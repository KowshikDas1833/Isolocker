# Isolocker
* A password protected private file manager app build in DroidScript
  
To use the app install DroidSript app in your device and open the file "DeepCase.spk" through it. After spk installation you can use it directly or create a package (.apk ) file if you have a droidscript premium access.

If you use directly, your created/moved file will be stored in droidscript's private storage. You can move back your files to local storage.

# Limitations:
1. For large list of files/folders loading is slow.
2. Password is not stored via hash crypt yet. Use the app at your own risk.
3. App crashes while loading 2k resolution pictures and videos.
